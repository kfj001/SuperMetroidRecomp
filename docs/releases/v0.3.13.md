Super Metroid now records diagnostic sessions automatically, following the
Mega Man X SNES recomp workflow. No toggle is needed for new or upgraded installs.

Each session saves a text log and bounded rolling gameplay replays with inputs,
machine checkpoints and presentation settings. Support can replay a recording
with the exact runtime/platform and owned JU ROM, checking WRAM, CPU, APU RAM and
VRAM after every execution. Save/load and rewind jumps carry new machine
checkpoints. Divergence and incomplete/crashed frames return failure with useful
evidence; playback writes into separate SRAM storage.

After a problem, quit normally if possible and attach the session's `logs/`
files and crash/exit reports. Include all replay segments and sidecars, never
your ROM. The bundled `replay_diagnostic.py` can inspect or replay captures;
Python is optional and is not required to play the game.

History is bounded to one hour and 256 MiB of machine checkpoints, plus bounded
input/settings sidecars. A fixed background queue handles disk writes and frame
hashing. Slow storage stops capture with a warning while gameplay continues.
Abrupt termination may lose the unflushed tail. Run-ahead and optional HLE suspend
capture; the default LLE gameplay path is supported. `SM_REPLAY_RECORD=0` opts out.

Windows x64, Linux x64, macOS Apple Silicon and macOS Intel remain precompiled
runtime downloads. Supply your own unmodified Super Metroid (Japan, USA) ROM.
Normal gameplay audio, SRAM and the existing widescreen/presentation mods remain
available. Host snapshots are build-specific; preserve guest SRAM when updating.
